# Booklify — Sistema de reservas para pequeños negocios

Aplicación web desarrollada en Laravel para gestionar reservas, servicios y horarios desde un flujo público simple y un panel administrativo.

## Características

- Reservas online
- Panel administrativo
- Gestión de servicios
- Validación de horarios
- Prevención de doble reserva
- Flujo público de reservas
- Interfaz responsive
- Dashboard administrativo

## Stack

- Laravel 12
- PHP
- MySQL
- Blade
- Tailwind CSS
- Vite

## Proyecto demo

Booklify fue desarrollado como una plataforma simple y moderna para reservas online orientadas a pequeños negocios y servicios.
